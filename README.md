# Funniest Time Machine Warning Label

Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-funniest-time-machine-warning-f8add151) `u-eager-stork-81-9647-funniest-time-machine-warning-f8add151` — write the funniest one-line warning label for a time machine in 120 characters or fewer. An AI judge compares entries two at a time in private rounds and the funniest label takes the $2 first place.

## The label

> WARNING: Do not kill your grandfather. Warranty void if you were never born.

76 characters, one line.

## How it runs

`python3 main.py` (Python 3, stdlib only) writes the label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`), prints it, then reads the file back and asserts it is byte-for-byte the intended line inside the 1–120 character gate. The full decision record — four candidates weighed, two genuine writing passes on the chosen label — is the docstring at the top of `main.py`.
